# 0009 自动协议选择

- 状态：提议
- 日期：2026-11-14
- 关联：原稿「代理模块」`protocol = "auto"`；ADR 0010、0013

## 背景

原稿要求自动选择依据连通性、延迟、失败率、优先级和冷却时间，不能凭单次请求切换。sing-box 自带 `urltest` 出站，可以按延迟自动选择，并支持 `tolerance` 和 `interval`，但没有失败率和冷却时间的概念，切换也不在 Norain 的审计范围内。

## 选项

| 选项 | 优点 | 缺点 |
|---|---|---|
| A. 使用 sing-box `urltest` | 实现最简单 | 无法实现失败率、冷却时间和审计；切换逻辑不可见 |
| B. 用 `selector` 出站，Norain 控制器负责测量和切换 | 满足原稿全部要求；切换有操作 ID 和日志 | 要启用 sing-box 的本地控制 API（`experimental.clash_api`），需要绑定回环地址并设置密钥 |
| C. 每次切换都重新生成配置并重启 | 不需要控制 API | 切换会中断已有连接 |

## 建议

选 **B**，阶段 2 之后实现。阶段 2 的校验器拒绝 `auto`，默认配置改为 `hysteria2`。

参数草案：

| 参数 | 草案值 |
|---|---|
| 探测目标 | `monitor_targets` 中标记为 `selection = true` 的 URL，默认用一个 204 响应端点 |
| 探测间隔 | 60 秒，每次对两个协议各探测一次 |
| 切换条件 | 当前协议连续 3 次失败；或者最近 5 次的延迟中位数比另一协议差 30% 以上且超过 100 ms |
| 冷却时间 | 一次切换后 10 分钟内不再切换，除非当前协议完全不可用 |
| 优先级 | 指标相同时 hysteria2 优先于 trojan，可配置 |
| 记录 | 每次切换记录原协议、新协议、触发条件、样本和操作 ID |

## 需要用户确认

1. 选项 B，以及阶段 2 之前 `auto` 不可用。
2. 参数草案是否合适。
