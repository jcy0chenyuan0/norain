# 0007 白/黑/蓝名单语义与分流优先级

- 状态：已接受（2026-11-14，见「确认」）
- 日期：2026-11-14
- 关联：原稿「分流模块」；ADR 0006、0008、0011

## 背景

原始产品目标里有「白名单、黑名单、蓝名单」，但没有定义。中文代理工具里这几个词的用法互相矛盾。例如「白名单模式」有时指「名单内直连、其余走代理」，有时指「只有名单内走代理」。原稿建议了四个精确字段名。

## 名称映射

| 原名称 | 字段 | 语义 | 状态 |
|---|---|---|---|
| 白名单 | `proxy_domains` | 强制走代理 | 用户已确认 |
| 黑名单 | `direct_domains` | 强制直连 | 用户已确认 |
| 蓝名单 | `isolation_allowlist` | 隔离模式下仍允许的连接 | 用户已确认 |
| （新增） | `monitor_targets` | 健康检测目标，不参与分流 |

以后代码和文档只使用右侧字段名，左侧名称只出现在本记录中。

## 建议：匹配语法

- 普通条目 `example.com` 按 `domain_suffix` 匹配，包括子域名。
- `full:example.com` 精确匹配。
- 首个版本不支持关键字和正则匹配，避免误伤。
- IP/CIDR 条目放在独立字段 `proxy_cidrs`、`direct_cidrs`，延后实现。

## 建议：决策顺序（从高到低，先命中先生效）

1. **隔离模式**（仅在隔离激活时）：命中 `isolation_allowlist` 的放行，其余全部拒绝，不再看后面的规则。
2. **内部保留**：发往代理服务器自身的连接、回环地址、私有网段直连，防止出现路由环路。
3. **显式规则**：`proxy_domains`、`direct_domains`。同一域名同时出现在两个列表中，配置校验直接报错，不做隐式优先。
4. **rule-set**：按配置中出现的顺序。
5. **默认动作**：`route.final`。默认走代理；可配置为直连。

补充约定：

- 分流结果不单独缓存，只缓存 DNS（ADR 0006）。
- GeoIP 类 rule-set 只能用于第 4 步，不能覆盖第 3 步的显式规则。

## 需要用户确认

1. ~~白/黑名单~~ → 已确认。「蓝名单」原意是不是隔离放行名单？
2. 默认动作是走代理还是直连？
3. 两个列表冲突时直接报错，而不是让其中一个优先。

## 确认

- 2026-11-14，用户：白名单 = 强制走代理，黑名单 = 直连；蓝名单 = 隔离模式下仍允许的连接；未命中任何名单的流量默认走代理。
- 「两个列表冲突时报错」未单独答复，按建议执行。
- 待定：最初目标中「按 DNS 解析位置加试连逐步判断、自动加入白名单」的流程与提示词「不能只凭解析位置决定分流」冲突，v0.4 开始前另立 ADR。

## 修订

2026-11-14，用户：**以最初目标（docs/reference/original-goals.md）为准，除非有硬性 bug。**

分流流程采用最初目标的四步：

1. 查白名单/黑名单：白名单走代理并由服务器解析 DNS，黑名单直连并用国内 DNS。
2. 都没命中时用本地 DNS 解析，判断国内还是国外，并按最初目标的 A/B/C 分支试连、必要时改判并加入白名单。
3. 仍无法判断时查 GeoIP 数据。
4. 查不到时交给服务器解析并走代理（即默认走代理）。

实现约束（硬性）：sing-box 1.12 起已移除内置 GeoIP 数据库，GeoIP 判断要用 rule-set 实现（ADR 0008）。「试连后改判并自动加入白名单」是 sing-box 做不到的动态行为，需要由 Norain 的内控制模块在 sing-box 之外实现，v0.4 开始前补一份设计。上文「GeoIP 不能单独决定分流」「不支持自动改判」的限制作废。

2026-11-15，用户：**默认的三类名单按本机现在装载的那套代理来设**。

- 白名单取本机 proxy-suite 的 sing-box.json 里 domain_suffix → proxy 的 87 条（OpenAI / Claude / Google / GitHub / 维基 等），
  黑名单为空（原配置没有显式直连域名，国内直连由 geosite-cn + geoip-cn 规则集承担），
  蓝名单取 network-guard.ps1 的 $allowSites（阻断期间仍放行 DeepSeek / B 站 / 知乎）。
- 落点：src/norain/defaults.py（唯一来源），由 install 模板、模型缺省值和 examples/cfg.toml 共同引用。
- 名单之外顺带对齐的机制：ip_is_private → direct、sniff、geosite-cn → 直连、DNS split（223.5.5.5 / 1.1.1.1 DoH 经代理）、
  trojan 多路复用（smux / 8 条流，取自原配置）。
